Early Fire Detection from IoT Sensor Data using AI

This repository contains the data preprocessing, model training, and evaluation code for our research on IoT-based fire detection.
It compares supervised tree models (XGBoost, Random Forest), semi-supervised anomaly detectors (Autoencoders, Isolation Forest), and a custom confidence-weighted hybrid ensemble. To ensure field-realistic performance, this project emphasizes strict leakage-aware time-block splitting, validation-only threshold calibration, and SHAP-based feature interpretability.
